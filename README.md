# Steampunk Engine — release binaries

Prebuilt binaries for the Steampunk Engine (MIT licensed, (c) 2026 Delta Zero Labs Corporation).

## Install (Linux x86_64, v0.2.0)

```sh
curl -LO https://github.com/Michael-A-Kuykendall/steampunk-releases/releases/download/v0.2.0/steampunk-0.2.0-linux-x86_64
curl -LO https://github.com/Michael-A-Kuykendall/steampunk-releases/releases/download/v0.2.0/SHA256SUMS
sha256sum -c SHA256SUMS
chmod +x steampunk-0.2.0-linux-x86_64
```

No source code or packs live here — binaries and checksums only.
